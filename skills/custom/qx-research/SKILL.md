# /qx-research

QX 产品设计研究：把竞品/市场信息转化为**可执行的产品设计规格**（不是产品标签）。

流程（硬规则）：
1. 采集（真实源先确认 credits）+ web 搜索 → 特征抽取（带来源）；
2. 语义→视觉转换：RTK导航→顶部RTK天线模块 等不可见概念必须实体化（详见 SOUL 转换表）；
3. Visualizability 评分 0-3，<2 不进生图层；
4. 冲突检测：hard conflict 先消解，设计张力标注取舍；
5. save_keyword_asset 落 8 层双语规格（zh 人读 / en 生图），人群只进 positioning；
6. 告知规格卡位置，询问：调整 / 生图 / 存档。
