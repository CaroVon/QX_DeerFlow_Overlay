## 〇、快速上手（新用户 5 分钟路径）

1. 打开入口 → 「Sign up」注册：填邮箱、密码、**邀请码**（向管理员索取）→ 自动进入工作台
2. 左侧「模板市场」→ 采用「🎯 关键词黄金路径」或任一「设计」模板
3. 左侧「Agents」→ 选刚采用的 agent 开聊：说"我想要便携咖啡机的设计关键词"
4. agent 确认采集消耗 → 提炼 **8 层关键词 Schema**（右侧面板可编辑卡）→ 点「生图（视图/套装）」→ 默认**解构图鉴**，或选 4 张套装一键
5. 右侧「生图任务」三态跟踪（排队中/生成中→完成出图/失败可重试）；每张卡可点「提示词」审计完整输入
6. 到「QX Studio → 资产库」点「导出作品 ZIP」拿到作品

## 一、功能使用指南

### 1. 账号与邀请码
- 注册需邀请码（单次有效，先到先得）；登录会话在服务重启后保持
- 管理员在「用量额度」页底部管理区：生成邀请码（可批量、可备注批次）、查看全员额度、发放/扣回三类额度
- 每个用户注册赠送：**50 万 LLM tokens / 20 张生图 / 50 采集 credits**
- **管理员不限额度**（操作只记账不拦截），保留发放/扣回权限

### 2. 聊天、Agent 与会话分离
- 输入框下方快捷按钮：[QX 全流程][研究][矩阵][生图]；输入 `/` 出技能补全
- **模板市场**（侧栏）：12 套官方模板（组合/研究/设计/演示四栏），一键采用即成为你的 agent（重名自动加后缀），去「Agents」开聊
- **会话列表任务指示**（W7）：会话右侧小圆点——旋转环=该会话有 QX 任务运行中/待审批（悬停可见状态），绿点=任务已完成；点击会话切换后，右侧任务面板自动只显示**当前会话**的任务与生图
- 无会话关联的历史生图收在任务面板底部「历史（无会话关联）」折叠区，不再混入当前会话
- 右侧「任务面板」按钮：进度/审批门/生图记录/关键词卡都在这里，可收起展开

### 3. 关键词 Schema 黄金路径（核心场景）
说"我想要 XX 产品的设计关键词" → agent 真实采集（**先确认消耗**）+ 搜索 → **8 层关键词 Schema** 落为右侧可编辑卡：
- 八层：身份/架构/几何/机构/部件/材料/硬件/环境；每条**中英双语**、可视化评分（0-3）、must/optional 优先级
- 卡片顶部可切「专业视图」：装配树 + 定位传导（人群→定位→约束），并有**冲突警示条**
- 直接增删改条目后保存；不想采集可说"用 mock"

### 4. 图鉴生图与提示词审计（Prompt Forge，v0.6 核心）
关键词卡上点「生图（视图/套装）」：
- **生图方式**：套装（图鉴+Hero+三视图+细节，一次 4 张）或 单视图（解构图鉴默认 / Hero / 三视图 / 细节 / 剖面）
- **风格**：9 档预设（自动/极简棚拍/工业手绘/生活方式/3D C4D/水彩/哑光 CMF/概念科幻/拼版版式）
- 挂载：不挂载（独立生图）或挂到某项目（同时进项目设计库）
- **组装在后台完成**（Prompt Forge）：骨架+关键词按层配额精选，确保不超 MiniMax 输入限制；提交后对话框显示「组装报告：入选 X 条 · 丢弃 Y 条 · prompt N/M 字符（Forge v…）」
- **审计入口**：生图记录每张卡（含排队中/生成中）右上角「提示词」按钮 → 弹窗展示 prompt **全文** + forge_report（视图/限制/入选/丢弃明细）——发给模型的每个字符可查
- 失败卡有「重试」；环境层关键词（如"农田作业"）不会进入图鉴 prompt（深色棚拍范式冲突，报告中记 view-conflict）

### 5. 生图与资产库（QX Studio → 资产库组块）
- 聊天生图、手动上传（图片/文档 ≤20MB）统一入库；**只看得到自己的资产**
- 每张图：预览放大、单独下载、挂载/取消挂载到项目（跨场景联动）、删除
- 「导出作品 ZIP」：打包本人全部已完成生图（作品集图片包）
- 筛选：全部 / 生图 / 文档 / 未挂载

### 6. 全流程任务（qx-full）
- 说"启动 QX 全流程：XX 产品"或点 [QX 全流程]：研究→MOD 矩阵→策略/PRD→设计→演示→PPT（约 30 分钟）
- 右侧面板实时节点进度；资料/大纲审核门到达时出现摘要卡可勾选批准
- Studio 页顶部「自动过门」开关：放手全自动（产物仍可回看）
- **终止任务**：面板内按钮，状态变灰色「已取消」（非失败），可放心终止
- 「任务资产 / 下载」：逐文件预览+单独下载；右上角「下载全部 ZIP」（二次下载秒回，已缓存）

### 7. 用量额度（侧栏「用量额度」）
- 三类余额卡 + 近 30 天消耗 + 流水明细（每一笔消耗/发放/退款可追溯）
- 「同步 LLM 用量」把对话消耗入账；额度不足的操作会被友好拦截（提示联系管理员）；**管理员不受拦截**
- 管理员附加：全员额度总览、按用户发放（正数发放/负数扣回）、邀请码生成
