# QX Studio 用户测试手册（v0.3）

入口：https://podcasts-spirit-debian-farmers.trycloudflare.com（本机 http://localhost:2026）
登录：admin@deerflow.qxdev.com / QxAdmin2026!

按序号逐条测试，遇到问题记录编号+现象反馈。

## A. 登录与会话

- [ ] A1 打开入口，登录后自动进入工作台，会话在服务重启后仍保持（不掉线）
- [ ] A2 头部品牌显示 "QX Studio"

## B. 聊天驾驶舱

- [ ] B1 新建聊天（左侧 Chats → 新对话），输入框下方可见 [QX 全流程][研究][矩阵][生图] 按钮，点击任一按钮输入框出现对应 /qx- 命令，回车可发送
- [ ] B2 输入 "/" 出现技能补全列表，含 qx-full / qx-image / qx-matrix / qx-research / style
- [ ] B3 直接说"生成一个便携咖啡机产品概念图"→ agent 不创建任务，1-6 分钟返回图片链接，**链接可直接点开看图**
- [ ] B4 说"用 mock 源采集 wireless mouse 竞品数据"→ 返回 8 条竞品摘要
- [ ] B5 提交全流程（说"启动 QX 全流程：XX 产品"）→ 右侧面板自动打开并切到"QX 任务"tab，显示节点进度
- [ ] B6 面板顶部有"任务面板"按钮：再点收起、再点展开（agent 自动打开后也能收起）
- [ ] B7 从左侧 Agents 选 qx-designer 对话 → **该聊天头部同样有"任务面板"按钮**
- [ ] B8 生图完成后，任务面板出现"生图记录"图片网格，点击可放大
- [ ] B9 任务运行中说"终止任务"→ 10 秒内节点停止，面板徽章变灰色"已取消"（非红色失败）
- [ ] B10 资料门到达时（审核模式），面板内出现 MOD 摘要卡（价格带/Top ASIN）+ 资料勾选列表，可勾选后批准
- [ ] B11 输入 "/style" → 列出四档风格，选"极简执行"→ 后续回复变一句话风格；新开对话仍生效

## C. Studio 工作台（左侧 QX Studio）

- [ ] C1 顶部为项目选择框（非左侧列表）：下拉切换任务，选项带 [状态] 前缀
- [ ] C2 画布居中：PPT 当前页在中心，8 个资产组块环绕；运行中组块流光
- [ ] C3 点击任意资产组块 → **居中大窗口**（约全屏 96%宽）展开详情
- [ ] C4 点击"任务资产 / 下载"→ **直接下载 ZIP 包**（非打开 JSON 文本）

## D. 资产模块（画布组块逐个点开）

- [ ] D1 资料源：门到达时展示完整审核视图；非门期显示状态说明
- [ ] D2 市场研究：TAM/SAM/SOM 四格 + 竞品威胁卡 + 痛点/差异化列表 + 引用源
- [ ] D3 策略/PRD：定位条 + 用户画像 + P0-P2 功能矩阵 + 路线图 + PRD 手风琴
- [ ] D4 MOD 矩阵：产物文件链接（pptx/图表/CSV），点击可下载
- [ ] D5 关键词：5 组编辑器（回车加词、X 删词）→ 保存；"用新词生图"按钮可触发生图并回显图片
- [ ] D6 设计：条目列表带**缩略图正常显示**；文字编辑/生图/版本历史恢复可用；"智能拆解组件"可创建组合
- [ ] D7 记忆图谱：本任务/全局切换；节点带 icon；**点击节点出解释**（摘要+关系列表）；空态有"立即抽取"按钮
- [ ] D8 演示/PPT：DSL 渲染器翻页（方向键/圆点）；缩略图流式填充；**页级返工**（hover 出现 👎，输入意见回车）；"在编辑器中打开（旧 SPA）"跳 8000 端口 GrapesJS；PPTX 下载
